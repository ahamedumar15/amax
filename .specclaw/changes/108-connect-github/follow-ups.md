- [minor B8] `apps/web/app/api/git/github/callback/route.ts:17` The callback copies `error_description` from the query string, and any exception's message, into `reason`. The Git accounts page then shows that text in a trusted status line. React escapes it, so it isn't XSS, but anyone can make a link that shows chosen text on amax's page, and internal error messages (database or authorization text) reach the user. Fix: map error codes to fixed messages, show only known, safe error messages from completeConnect, and log the rest. (round 1) <!-- fp:a6e040353d03 class:security -->

Fix: pass a real array parameter (sql`= any(${emails})` with an array bind, or sql.join). (round 1) <!-- fp:8c64fd9296a6 class:other -->
