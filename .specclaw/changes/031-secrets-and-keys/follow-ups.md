- [minor B8] `packages/core/src/secrets/crypto.ts:20` open() takes the auth tag by slicing and never fixes its length. Fix: pass { authTagLength: 16 } to createDecipheriv and reject input shorter than 28 bytes. (round 1) <!-- fp:0cabd4af4b76 -->
- [minor B5] `packages/core/src/secrets/runtime.ts:41` secrets.data_key.kms is written but never read. dataKeyFor hands any stored blob to whichever KMS is configured now. Fix: compare row.kms with k.id and fail with a clear error when they differ, and set retryable only for 5xx and 429. (round 1) <!-- fp:181e67c901d6 -->
